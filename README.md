# Data-analysis-Dashboard
Interactive Walmart Sales Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and KPIs. Analyzes sales, profit, orders, quantity, market performance, product trends, regional distribution, and category insights through dynamic visualizations to support data-driven business decision-making.

Walmart Sales Dashboard - Detailed Project explaination 

Executive Summary 

This project develops an interactive Walmart Sales Dashboard in Microsoft Excel to analyze sales performance across markets, categories, segments, cities, products, and countries. The dashboard enables business users to monitor KPIs and identify trends through an intuitive visual interface. 

Project Objectives 

Track Total Sales, Profit, Orders, and Quantity. Compare performance across Markets, Segments, Categories, and Regions. Identify top and bottom performing products. Enable self-service analysis through slicers and filters. 

Dataset Overview 

The sales dataset contains transactional information including Order Date, Market, Segment, Category, Product Name, Sales, Profit, Quantity, City, and Country. Historical records were organized to support multidimensional analysis. 

Data Cleaning and Preparation 

Validated data types, removed duplicates, checked blanks and null values, standardized categorical values, verified numeric fields, and prepared data for Pivot Table reporting. 

Data Modeling Approach 

A tabular data model was used. The source dataset was converted into an Excel Table to provide dynamic expansion and efficient Pivot Table creation. 

KPIs 

Total Orders: 928. Total Sales: 0.47M. Total Profit: 0.06M. Total Quantity Sold: 3356. These KPI cards provide a quick executive overview. 

Dashboard Visuals 

Sales by Segment, Sales by Category, Sales by Market, Top 5 Cities, Top 5 Products by Quantity, Bottom 5 Products by Sales, Bottom 5 Products by Quantity, Region Market Share, Top Sub-Categories Contribution, and Country Sales Map. 

Slicer Functionality 

Year, Market, Segment, and Category slicers are connected to multiple Pivot Tables and Charts, allowing dynamic filtering across the entire dashboard. 

Business Insights 

Consumer segment contributes a significant portion of revenue. Technology products perform strongly. Market-wise variations indicate different customer demand patterns. Product-level analysis reveals opportunities for inventory optimization and profitability improvement. 

Excel Features Used 

Excel Tables, Pivot Tables, Pivot Charts, Slicers, Sorting, Aggregations, KPI Cards, Conditional Formatting, Data Validation, Dashboard Formatting, and Interactive Reporting. 

Challenges and Solutions 

Maintained consistent slicer connectivity, optimized chart layouts, ensured dashboard readability, standardized KPI calculations, and improved visual presentation for executive stakeholders. 

Business Value 

Provides faster reporting, reduces manual analysis effort, supports decision-making, identifies profitable opportunities, and improves visibility into sales performance. 

Future Enhancements 

Power Query automation, Power Pivot data model, forecast analysis, customer segmentation, profitability analysis, and migration to Power BI for enterprise-scale reporting. 

Conclusion 

The Walmart Sales Dashboard demonstrates practical business intelligence capabilities using Microsoft Excel. It converts raw sales data into meaningful insights through interactive visual analytics and supports data-driven decision-making.
